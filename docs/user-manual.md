# Artistry User Manual

## Overview
Artistry is a marketplace for discovering artisan products, previewing them in AR, chatting with sellers, and placing orders online. The system has three roles:

- Customer: browse products, buy items, track orders, and contact support
- Seller: manage products, orders, shipping, payments, and support messages
- Admin: review sellers, manage users and orders, and answer support concerns

## 1. Customer Guide

### 1.1 Open the website
Go to the Artistry home page. From there, you can:

- Browse featured and latest collections
- Search products using the search bar
- Open artisan profiles and directories
- Read the About, Terms and Conditions, and Privacy Policy pages

### 1.2 Create an account or sign in
Use the Login page to sign in as a customer.

If you forgot your password:

1. Open the Forgot Password page
2. Enter your email address
3. Follow the reset link or instructions sent to you
4. Set a new password on the Reset Password page

### 1.3 Browse products
Use the Collection page or search bar to find products.

On a product page, you can usually:

- View product images and details
- Check price, available colors, and sizes
- Read reviews and ratings
- Open the seller or artisan profile
- Start a chat with the seller
- Add the item to your cart

### 1.4 Use AR preview
Some products support AR viewing.

To preview a product in AR:

1. Open the product page
2. Click the AR view option
3. Allow camera permissions if prompted
4. Position the product in your space and adjust the view as needed

AR is most useful for products that support dimensions or 3D models.

### 1.5 Add items to cart
From the product page, choose the available options first, such as color or size, then add the item to your cart.

In the Cart page, you can:

- Review items before checkout
- Change quantity
- Remove items
- View the total amount
- Continue to checkout

### 1.6 Place an order
Open the Place Order page to complete checkout.

You will typically need to provide:

- Full name
- Mobile number
- Complete delivery address
- Zip code
- Email address

During checkout, you can:

- Use your saved profile address if available
- Choose a payment method such as Cash on Delivery or GCash
- Upload a GCash receipt when required
- Review shipping or pickup information shown for the seller

After submitting the order, check the Orders page for updates.

### 1.7 Track orders
Use the Orders page to see your purchases.

You can open an order to view:

- Order status
- Items included in the order
- Payment details
- Delivery or fulfillment progress

### 1.8 Manage your profile
The Profile page lets you update your account details, including:

- Name
- Email
- Phone number
- Address fields
- Country

You can also log out from this page.

### 1.9 Contact support
Use the Support page if you need help with:

- Orders
- Payments
- Account access
- Platform issues

You can send text messages and attach images when needed.

### 1.10 View notifications
The Notifications page shows platform updates and important account or order messages.

## 2. Seller Guide

### 2.1 Sign in as a seller
Use the Seller Login page.

If you forgot your password:

1. Open Seller Forgot Password
2. Enter your seller email
3. Follow the reset instructions
4. Set a new password on Seller Reset Password

### 2.2 Open the seller dashboard
After login, the Seller Dashboard is the main control center.

From there, sellers can:

- View and manage products
- Review seller orders
- Manage product stock and listings
- Update shipping settings
- Update payment settings
- Manage return policy
- Read and reply to chats
- Review customer feedback

### 2.3 Manage products
Sellers can create and edit product listings with information such as:

- Product name and description
- Price
- Category and subcategory
- Available colors and sizes
- Stock
- Materials
- Size charts and dimensions
- Product images and 3D models

If a product supports AR or size metadata, the seller should keep those details accurate so customers can preview it correctly.

### 2.4 Handle orders
The Seller Orders page shows orders related to the seller.

Sellers should use it to:

- Check new orders
- Update order status
- Review order details
- Coordinate fulfillment and pickup

### 2.5 Configure payment and shipping
In the dashboard, sellers can set:

- Shipping rates
- Free shipping thresholds
- Processing time
- Pickup locations
- Cash on Delivery availability
- GCash account details and QR code

### 2.6 Reply to messages
Sellers can communicate with customers through the support or chat features.

Use this to:

- Answer product questions
- Clarify shipping or pickup details
- Resolve issues before or after purchase

### 2.7 Update seller profile
The Seller Profile page is used to manage store identity and account details.

## 3. Admin Guide

### 3.1 Sign in as admin
Use the Admin Login page.

### 3.2 Open the admin dashboard
The Admin Dashboard is the main admin workspace.

Admins can:

- Review and verify sellers
- View customers
- Review orders
- Manage support conversations
- Remove or review records when needed

### 3.3 Verify sellers
If a seller needs verification, the admin can open the seller record in the dashboard, review submitted proof, and verify the seller.

### 3.4 Support channel
Admins answer messages in the support area for both customers and sellers.

## 4. Common Workflows

### Browse and buy
1. Open the Home or Collection page
2. Select a product
3. Choose color, size, or other options
4. Preview in AR if available
5. Add to cart
6. Open Cart
7. Proceed to checkout
8. Place the order

### Change a password
1. Open the appropriate Forgot Password page
2. Submit your email
3. Follow the reset instructions
4. Sign in again with the new password

### Contact a seller or admin
1. Open the product page or support page
2. Send a message
3. Attach an image if needed
4. Wait for a reply in the same conversation

## 5. Tips for Users

- Make sure your delivery address is complete and accurate before checkout
- Use a valid Philippine mobile number if you are placing an order in the Philippines
- Keep your product options consistent before adding items to cart
- Upload clear images when chatting about a problem or payment concern
- Save important order details for later reference

## 6. Troubleshooting

If you cannot sign in:

- Confirm your email and password are correct
- Use the password reset page if needed
- Make sure you are using the right login page for your role

If a page does not load correctly:

- Refresh the page
- Check your internet connection
- Try again after a short wait if the backend is waking up

If an order does not appear:

- Confirm that checkout finished successfully
- Check the Orders page again after refreshing
- Contact support if the issue continues
